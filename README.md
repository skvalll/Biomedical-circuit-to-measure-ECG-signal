# Biomedical Circuit for Basic ECG Signal Measurement

## Overview

This project focuses on the design of a basic ECG (Electrocardiogram) measurement circuit for heart rate signal acquisition. The circuit was designed using **KiCad**, including both **schematic design** and **PCB layout**.

The project is intended for basic academic and educational purposes, providing a simple implementation for studying ECG signal acquisition and analog circuit design.

## Features

* Basic ECG signal acquisition circuit
* Heart rate signal measurement
* Schematic design using KiCad
* PCB layout design using KiCad
* Basic analog signal conditioning

## Tools

* **KiCad** – Schematic and PCB design
* **PCB Design** – Component placement and routing
* **ECG Signal Acquisition** – Basic heart rate measurement

## Design

The project consists of two main design stages:

### Schematic

The schematic was developed in KiCad to define the electrical connections and signal-processing stages of the ECG measurement circuit.

### PCB Layout

The PCB layout was designed in KiCad based on the schematic, including component placement and PCB routing.

## Purpose

This project was developed as a basic electronics and PCB design project to practice:

* ECG signal acquisition
* Analog circuit design
* Schematic design
* PCB layout
* KiCad workflow
